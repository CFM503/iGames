**iGames** 是一款专为儿童早期生活规范与好习惯养成设计的轻量级原生 Android 游戏合集平台。采用模块化架构，界面采用大圆角、高饱和柔和护眼色彩与灵动的触控动效，引导孩子在快乐的微游戏中理解规则、学会自理。

项目深度集成了 **GitHub Actions 在线云编译** 与 **应用内在线自动检查更新** 功能，无需在本地配置繁重的 Android SDK / Java 环境，直接在 GitHub 云端即可一键编译，安装到手机后也能自动检测最新 GitHub Release 并一键升级！

## 🚦 首发游戏：红绿灯模拟器与互动小交警

### 1. 拟真信号灯模拟器（过家家好搭档）
- **屏幕常亮保活**：开启后自动保持常亮（Keep Screen On），可将手机/平板直接立在玩具道路旁当真实信号灯。
- **4 种专业信号灯样式**：
  - 🟢 **经典三色信号灯**：拟真遮阳帽檐、蜂窝透镜玻璃反光与发光光晕。
  - 🚶 **行人过街信号灯**：静态红灯静止小人、动态绿灯**踏步迈步双腿行走动效**。
  - 🔢 **超大数字倒计时灯**：圆环进度条与大号数码管读秒。
  - ⏱️ **复合倒计时信号灯**：机动车三色灯与倒计时并列显示。
- **声音与语音系统**：
  - 童声语音口诀：“绿灯亮，向前行！”、“黄灯亮，等一等！”、“红灯亮，快停下！”
  - 拟真提示音、盲道过街提示蜂鸣音、倒计时滴答声。
- **手动小交警模式**：支持一键切换为手动模式，孩子可化身小交警，轻触红黄绿按钮自主控制信号灯切换。

### 2. 规则互动小游戏（小司机过马路）
- 屏幕下方模拟道路斑马线与卡通小汽车。
- **玩法**：按住大按钮向前开，绿灯安全前进，黄灯小心减速；若在红灯时前进，小车会触发趣味警示音并退回起点。
- 成功穿过斑马线获得金灿灿的“小星星”奖励，培养规则意识与专注力。

### 3. 家长/教师自定义设置（带儿童防误触锁）
- **儿童锁（Parental Gate）**：点击设置按钮会弹出趣味简易加减算术题验证（如 $3 + 5 = ?$），防止低幼儿童误触打乱参数。
- **时长自由配置**：绿灯（3~60s）、黄灯（1~10s）、红灯（3~60s）秒级滑块调节。
- **参数本地记忆**：采用 Jetpack DataStore，重启应用依然保留设置。

## 🚀 GitHub Actions 在线云编译与发布指南

无需在电脑上安装数百兆的 Android Studio 或配置 Java SDK，只需将代码推送到 GitHub：

### 1. 自动触发云端打包
- **推送代码**：每次向 `main` 分支 push 代码，GitHub Actions 会自动触发构建任务。
- **下载测试 APK**：在 GitHub 仓库的 **Actions** 标签页中，点击最近的运行记录，在页面底部的 **Artifacts** 区域即可直接下载 `iGames-Android-APKs`。

### 2. 发布正式 Release 版本
当您准备发布一个正式版本供其他手机在线更新或直接下载时，只需打一个版本 Tag 并推送到 GitHub：
```bash
git tag v1.0.0
git push origin v1.0.0
```
GitHub Actions 会自动编译 Release APK，并挂载到 GitHub Release 页面，手机端的 iGames 即会检测到新版本并提示在线更新！
